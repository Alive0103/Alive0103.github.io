## 修复：文章目录（TOC）为空
- 症状：「是啊，我也曾彻夜难眠」正文有章节但右侧目录为空。
- 根因：章节用的是 `# 大一`（**一级标题**）。Valaxy/Yun 的 TOC（`useOutline` → `getHeaders`）**不收录 h1**，只从 h2 开始；h1 虽有 `id`（产物里 `<h1 id="大一">`），但不在默认 range 内。
- 修复：`# 大一~大四` → `## 大一~大四`。
- 注意：「实习小记」全文没有任何 `#` 标题（纯 Q&A 段落），所以本来就没有目录；要目录需加 `##` 章节标题。
- 规律：Valaxy 文章**章节标题从 `##` 开始写**，`#` 留给 frontmatter 的 title。

## 方案变更：随笔移出 posts，彻底弃用 hide/draft
- 用户要求"文章栏主动排除 essays，不用 hide/draft"。
- 关键结论：Valaxy 文章栏/首页/归档/分类/RSS **统一按 `/posts` 前缀聚合**（`filterAndSortPosts`），**没有"排除某子目录"的配置**；要保留 `posts/essays/` 再排除需覆盖多个组件，且 RSS 是构建期 node 端，组件覆盖够不着。所以**最干净的方式是把 essays 移出 posts**。
- 实施：`pages/posts/essays/*.md`（16 篇）→ `pages/essays/`（与已有 index.md 网格页同目录）。`startsWith('/posts')` 天然排除 → 文章栏/首页/归档/RSS 全不含随笔；删掉全部 hide/draft；文章页无状态图标。URL `/posts/essays/x` → `/essays/x`。
- `components/PostGrid.vue` 的 prefix 从 `/posts/${folder}/` 改为 `/${folder}/`（folder 现为相对 pages 根的完整目录，如 `essays` 或 `posts/tech`），空状态文案同步改 `pages/{{folder}}/`。
- tech/work 的文章仍保留 `draft: true`（用户未写完，不进生产）；essays 已去 draft 全部上线。
- 验证：/posts/ 与首页文章流不含 essays；/essays/ 生产网格 16 卡；归档/RSS 无 essays；/essays/<标题> 文章页可访问。

## 教训：内容覆盖
- 09-28 我用 Write 覆盖了「随笔.md」（当时它是 0 字节空文件）。用户以为里面有内容（很多一级标题），实际从未保存到磁盘——git 未提交、VS Code History 无记录、无 Time Machine 快照，**确认无法恢复**。用户随后手动重新粘贴了内容。
- 教训：覆盖用户文件前，哪怕它显示为空，也要先和用户确认；尤其标题类占位文件，用户可能在编辑器里写了没保存。
