- 探测命令：`curl -X POST "https://<envId>.api.tcloudbasegateway.com/v1/signin/anonymously" -H "Origin: <待测origin>" -H 'content-type: application/json' -d '{}'`
  - `403` 空 body = 该 origin 不在安全域名白名单

## CloudBase 云存储当图床（可行，已实测）
- 存储桶：`616c-alive0-0-d7gvevz0laacc7bd3-1314400788`，CDN 域名 `616c-alive0-0-d7gvevz0laacc7bd3-1314400788.tcb.qcloud.la`。
- 默认 ACL 是 PRIVATE，必须 `managePermissions(updateResourcePermission, resourceType=storage, permission=READONLY)` 改公有读，publicUrl 才能匿名访问（改前 403，改后 200）。
- 外链格式：`https://<CdnDomain>/<cloudPath>`；`manageStorage(upload)` 返回的 temporaryUrl 只有 1 小时，不能写进文章。
- 与阿里云 OSS 对比：无 `x-oss-process` 类即时处理参数（缩放/水印需上传前自己处理或另开数据万象）。
- 计费项（`queryEnv action=usage` 的 COS 模块可见）：`Capacity`（存储 MB）、`ReadRequests` / `WriteRequests`（请求次数）、`Flux`（外网下行流量 Byte）、CDN `Flux`（CDN 流量）——即图床的「读」确实计费：流量 + 读请求次数两项。阿里云 OSS 同样收这两项，所以换成 CloudBase 是费用转移而非新增。

- 官方 `cloudbase` skill 本机已随 CloudBase 插件安装（v2.34.6，位于 `~/.workbuddy/plugins/cache/workbuddy-connector-plugins-official/cloudbase/*/skills/cloudbase`），与 `TencentCloudBase/cloudbase-skills` 同一份，无需再 `npx skills add`；它是纯 markdown 指导型，无脚本，安全（P2）。其 cloudbase-platform 文档也确认安全域名入口就是 `manageEnv(addSecurityDomain)`，因此装 skill 也不能绕过套餐限制。

## 已解决：EXCEED_AUTHORITY（云函数安全规则）
- 现象：提交评论报 `EXCEED_AUTHORITY`；查 CLS 日志确认**浏览器请求根本没到达云函数**（日志里只有管理端调用），说明被网关鉴权层拦下。
- 根因：新环境云函数安全规则默认是 `{"*":{"invoke":"auth != null && auth.loginType != 'ANONYMOUS'"}}`（拒绝匿名调用），Twikoo 走匿名登录 → 被拒。
- 关键坑：`managePermissions(updateResourcePermission, ..., resourceId="twikoo")` 返回 Success 但**规则实际没变**（该 API 不接受 ResourceId，参数被静默忽略）。必须用 `callCloudApi(service=tcb, action=ModifyResourcePermission, params={EnvId, ResourceType:"function", Permission:"CUSTOM", SecurityRule})`，**不要带 ResourceId**；改完 `getResourcePermission` 立刻显示 `{"*":{"invoke":true}}`。
- 环境还配了 OPA 策略 `authz.user.rego`（允许 resource_type=="functions"），但老网关调用不读它。
- 排查辅助：`queryLogs(searchLogs, service=tcb, queryString='(src:app OR src:system) AND log:"START RequestId"')` 可看真实调用；`queryFunctions(listFunctionLogs)` 已废弃。
- 附带：新环境未生成 publishable key，已用 `manageAppAuth(ensurePublishableKey)` 生成（keyId `Oem-oJnLSKqdgiVMOqTekA`，2099 到期）。
- 注意：老 API `tcb-api.tencentcloudapi.com/web` 仍报 `anonymous authentication is disabled for the env`（新控制台的匿名登录开关可能与老 API 不同步），若后续仍有问题需从这一侧排查。
