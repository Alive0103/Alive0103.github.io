### 坑（重要）
- **自定义 layout 里不要靠 `<RouterView v-slot>` 给 ValaxyMain 传 `#main` slot**——SSG 下 slot 不会透传，
  内容整个丢失（主题自带的 albums.vue 也是这个写法，同样不生效）。直接把内容写在 layout 里即可。
- 构建时**不要用 `npm run build | head -N`**：管道提前关闭会 SIGPIPE 杀掉构建，dist 只剩残缺产物。
  应 `npm run build > /tmp/x.log 2>&1` 再读日志。
