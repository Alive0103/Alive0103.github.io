## Agent

1. **[OpenAI 发布 Dots：自带云电脑的"常驻智能体"](https://www.ajnvgmedia.com/chatbots-to-always-on-ai-why-openai-meta-google-want-persistent-agents)**
   DevDay 上发布，每个 Dot 拥有独立云端电脑和浏览器，可连 4000+ 应用，会话结束后仍在后台干活；双窗口设计让用户实时围观它工作。

2. **[Meta Muse 与 Google Gemini Spark 跟进，"常驻"成三家共同方向](https://www.ajnvgmedia.com/chatbots-to-always-on-ai-why-openai-meta-google-want-persistent-agents)**
   Muse 跑在专属虚拟机里，配 Sentinel 行为监控系统；Spark 主打 24/7 后台运行，设备关机也不停。行业从"聊天工具"转向"持久同事"。

3. **[Manus 2.0：Cascade 架构宣称省 23% token、降 32% 成本](https://dayaai.com/news/story/4612)**
   Automations 支持邮件/Slack 事件触发任务，Computer Use 可操控本机授权应用；新应用 Cue 给每个智能体独立邮箱、钱包和电脑。数据未经独立验证。

4. **[Cloudflare 开源决策模型 Clef / Clef-flash](https://blog.cloudflare.com/clef-decision-models/)**
   基于 Qwen、Apache 2.0 协议，目标是让 agent 在"无需人工确认"的场景下做结构化决策；Clef-flash 单次分类约 39ms，比上一代方案快十倍。

5. **[Google：Gems 11 月起过渡为 Skills](https://www.ajnvgmedia.com/chatbots-to-always-on-ai-why-openai-meta-google-want-persistent-agents)**
   自定义指令不再是用户手动挑用的"Gem"，而是 agent 按需自动识别、可组合的 Skill。与 Anthropic/Claude 的 Skills 生态趋同。

6. **[GitHub Trending 今日清一色 agent 基建](https://github.com/trending)**
   NVIDIA OpenShell（agent 安全运行时，Rust）、openrig（跨 Claude Code/Codex 的持久多 agent 团队）、codegraph（本地代码知识图谱省 token）、caveman（砍 65% token）、Agent-Reach（今日 +683★）。

7. **[Datawhale 发布《Jev Cookbook》：决策模型中文教程](https://mp.weixin.qq.com/s/umCvohse7L0oAc8MEPdaLQ)**
   11 章系统讲解 + 18 篇可运行 Notebook，覆盖 RAG 引用过滤、动态工具路由、风险拦截等 Agent 典型链路，并对 Jev 与多个主流模型做统一横评，除准确率外还记录有效回答率、延迟与成本。开源地址 github.com/datawhalechina/jev-cookbook。与今日 Clef 是同一技术方向：让作业员式判断从 Prompt 里拆出来，交给专用决策模型。

20. **[arXiv：系统提示词幻觉——提示词前缀到底改了模型什么计算](https://arxiv.org/abs/2609.38205)**
    系统提示是从业者控制模型行为的主要手段，但很少有研究说明它究竟对模型内部计算做了什么；本文用机制性方法拆解这一层。
21. **[arXiv：Agent 里的微任务，什么时候一个小模型就够了](https://arxiv.org/abs/2610.00025)**

    编译器、测试套件、仓库命令这类长耗时工具会主导编码 agent 的延迟；论文提出乱序投机执行来掩盖这段等待。

### 后端

23. **[Zig 0.17.0 发布：构建系统重构，增量编译走向实用](https://ziglang.org/download/0.17.0/release-notes.html)**
    206 位贡献者、925 次提交；引入 Build Server Protocol（`--listen=-` 供 IDE 驱动构建图），新 ELF 链接器增强后 `x86_64-linux` 增量编译（`-fincremental --watch`）对多数项目可用；标准库用 `SafeAllocator` 取代 `DebugAllocator`，标准库测试 wall_time -24.7%、peak_rss -50.3%。同时 `@cImport` 被移除、移出 GitHub 到 Codeberg。
24. **[Redis 作者 antirez 的新项目 ds4：本地跑前沿开源模型](https://dwarfstar.sh/)**
    一个刻意做窄的 C 推理引擎，支持 DeepSeek V4/V4.1、GLM 5.x、Qwen3.8；靠非对称 2-bit 量化压缩 routed experts、KV cache 落盘按 prompt hash 续跑；MIT 许可，Metal/CUDA/ROCm，M5 Max 128GB 上 32K 上下文实测 34.4 tok/s 生成。
25. **[Cloudflare AI Gateway 原生支持 Web Search API](https://blog.cloudflare.com/introducing-web-search-api/)**
    与 Ceramic.ai、Exa、Linkup 合作，开发者可以在模型推理时直接注入实时网页上下文，不必自己维护检索链路。
26. **[arXiv：Guarded Commits，把人工审批做成 LLM 工作流里的事务](https://arxiv.org/abs/2610.00037)**
    不可逆外部动作前需要人工批准，但现有系统把审批放在工作流之外；论文把审批纳入事务语义，避免"批准了但没执行/执行了但没记录"的错位。
