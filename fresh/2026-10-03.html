Agent ​

  1. OpenAI 发布 Dots：自带云电脑的"常驻智能体" DevDay 上发布，每个 Dot 拥有独立云端电脑和浏览器，可连 4000+ 应用，会话结束后仍在后台干活；双窗口设计让用户实时围观它工作。

  2. Meta Muse 与 Google Gemini Spark 跟进，"常驻"成三家共同方向 Muse 跑在专属虚拟机里，配 Sentinel 行为监控系统；Spark 主打 24/7 后台运行，设备关机也不停。行业从"聊天工具"转向"持久同事"。

  3. Manus 2.0：Cascade 架构宣称省 23% token、降 32% 成本 Automations 支持邮件/Slack 事件触发任务，Computer Use 可操控本机授权应用；新应用 Cue 给每个智能体独立邮箱、钱包和电脑。数据未经独立验证。

  4. Cloudflare 开源决策模型 Clef / Clef-flash 基于 Qwen、Apache 2.0 协议，目标是让 agent 在"无需人工确认"的场景下做结构化决策；Clef-flash 单次分类约 39ms，比上一代方案快十倍。

  5. Google：Gems 11 月起过渡为 Skills 自定义指令不再是用户手动挑用的"Gem"，而是 agent 按需自动识别、可组合的 Skill。与 Anthropic/Claude 的 Skills 生态趋同。

  6. GitHub Trending 今日清一色 agent 基建 NVIDIA OpenShell（agent 安全运行时，Rust）、openrig（跨 Claude Code/Codex 的持久多 agent 团队）、codegraph（本地代码知识图谱省 token）、caveman（砍 65% token）、Agent-Reach（今日 +683★）。

  7. Datawhale 发布《Jev Cookbook》：决策模型中文教程 11 章系统讲解 + 18 篇可运行 Notebook，覆盖 RAG 引用过滤、动态工具路由、风险拦截等 Agent 典型链路，并对 Jev 与多个主流模型做统一横评，除准确率外还记录有效回答率、延迟与成本。开源地址 github.com/datawhalechina/jev-cookbook。与今日 Clef 是同一技术方向：让作业员式判断从 Prompt 里拆出来，交给专用决策模型。
