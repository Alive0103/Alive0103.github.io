Agent ​

  1. OpenAI 发布 Dots：自带云电脑的"常驻智能体" DevDay 上发布，每个 Dot 拥有独立云端电脑和浏览器，可连 4000+ 应用，会话结束后仍在后台干活；双窗口设计让用户实时围观它工作。

  2. Meta Muse 与 Google Gemini Spark 跟进，"常驻"成三家共同方向 Muse 跑在专属虚拟机里，配 Sentinel 行为监控系统；Spark 主打 24/7 后台运行，设备关机也不停。行业从"聊天工具"转向"持久同事"。

  3. Manus 2.0：Cascade 架构宣称省 23% token、降 32% 成本 Automations 支持邮件/Slack 事件触发任务，Computer Use 可操控本机授权应用；新应用 Cue 给每个智能体独立邮箱、钱包和电脑。数据未经独立验证。

  4. Cloudflare 开源决策模型 Clef / Clef-flash 基于 Qwen、Apache 2.0 协议，目标是让 agent 在"无需人工确认"的场景下做结构化决策；Clef-flash 单次分类约 39ms，比上一代方案快十倍。

  5. Google：Gems 11 月起过渡为 Skills 自定义指令不再是用户手动挑用的"Gem"，而是 agent 按需自动识别、可组合的 Skill。与 Anthropic/Claude 的 Skills 生态趋同。

  6. GitHub Trending 今日清一色 agent 基建 NVIDIA OpenShell（agent 安全运行时，Rust）、openrig（跨 Claude Code/Codex 的持久多 agent 团队）、codegraph（本地代码知识图谱省 token）、caveman（砍 65% token）、Agent-Reach（今日 +683★）。

  7. Datawhale 发布《Jev Cookbook》：决策模型中文教程 11 章系统讲解 + 18 篇可运行 Notebook，覆盖 RAG 引用过滤、动态工具路由、风险拦截等 Agent 典型链路，并对 Jev 与多个主流模型做统一横评，除准确率外还记录有效回答率、延迟与成本。开源地址 github.com/datawhalechina/jev-cookbook。与今日 Clef 是同一技术方向：让作业员式判断从 Prompt 里拆出来，交给专用决策模型。

后端 ​

  1. turbopuffer：《RIP, vector database》 宣称专用向量数据库的时代正在终结——向量检索作为对象存储之上的一层索引即可。HN 270 分，争论激烈，值得读原文和评论区。

  2. Cloudflare K2：Serverless 事件流 面向事件驱动架构的托管流服务，Kafka 类语义 + Serverless 付费模型，后端事件总线又多一个托管选项。

  3. GitButler：Git 3.0 默认 SHA-256 将是一次代价高昂的错误 论点集中在生态兼容成本与迁移收益不匹配。HN 213 分，适合关注版本控制底层的人。

  4. Rust 编译器 9 月提速纪实 Nicholas Nethercote 的月度性能报告，持续近十年的增量优化传统的又一篇，附具体数据。

Agent 与大模型 ​

  1. Ai2 开源 AstaBrief 8B：一次成稿的科学报告生成模型 基于 Qwen3-8B 做 SFT + DPO（明确不用 RL），输入研究问题加检索文献片段，一遍生成带引用的完整报告；在 Asta 中作为 Fast mode，平均 51.1 秒/份，对比 Claude 驱动的 Thinking mode 178.5 秒。
  2. GitHub Trending：agent 基建与 skills 生态继续霸榜 ponytail（+1435★，"让 agent 像最懒的资深工程师那样思考"）、obra/superpowers（+556★，agentic skills 框架）、NVIDIA OpenShell（+594★，Rust 写的 agent 安全运行时）、openrig（+683★，跨 Claude Code/Codex 的持久多 agent 团队）、context-mode（+282★，工具输出沙箱化，宣称削减 98%）。
  3. OpenAI 发布 GPT-6 系列选型指南 面向创业公司的实操文档：怎么选模型、怎么调 reasoning effort、怎么写 prompt 和 skill、怎么协调工具、怎么为生产环境做准备。
  4. Black Forest Labs 发布 FLUX 3 Image 主打多步编辑只改局部、不动画面其他地方；HN 271 分。同日 Ideogram 也发布了同类局部编辑模型。
  5. arXiv：系统提示词幻觉——提示词前缀到底改了模型什么计算 系统提示是从业者控制模型行为的主要手段，但很少有研究说明它究竟对模型内部计算做了什么；本文用机制性方法拆解这一层。
  6. arXiv：Agent 里的微任务，什么时候一个小模型就够了 当前做法是在前沿大模型周围用小模型跑微任务，论文给出"微任务资格差距"的量化方法，划定 off-the-shelf 小模型够用与不够用的边界。
  7. arXiv：TomasuLLM，给 LLM agent 做乱序投机执行 编译器、测试套件、仓库命令这类长耗时工具会主导编码 agent 的延迟；论文提出乱序投机执行来掩盖这段等待。

后端 ​

  1. Zig 0.17.0 发布：构建系统重构，增量编译走向实用 206 位贡献者、925 次提交；引入 Build Server Protocol（--listen=- 供 IDE 驱动构建图），新 ELF 链接器增强后 x86_64-linux 增量编译（-fincremental --watch）对多数项目可用；标准库用 SafeAllocator 取代 DebugAllocator，标准库测试 wall_time -24.7%、peak_rss -50.3%。同时 @cImport 被移除、移出 GitHub 到 Codeberg。
  2. Redis 作者 antirez 的新项目 ds4：本地跑前沿开源模型 一个刻意做窄的 C 推理引擎，支持 DeepSeek V4/V4.1、GLM 5.x、Qwen3.8；靠非对称 2-bit 量化压缩 routed experts、KV cache 落盘按 prompt hash 续跑；MIT 许可，Metal/CUDA/ROCm，M5 Max 128GB 上 32K 上下文实测 34.4 tok/s 生成。
  3. Cloudflare AI Gateway 原生支持 Web Search API 与 Ceramic.ai、Exa、Linkup 合作，开发者可以在模型推理时直接注入实时网页上下文，不必自己维护检索链路。
  4. arXiv：Guarded Commits，把人工审批做成 LLM 工作流里的事务 不可逆外部动作前需要人工批准，但现有系统把审批放在工作流之外；论文把审批纳入事务语义，避免"批准了但没执行/执行了但没记录"的错位。

客服与对话系统 ​

  1. 微软 AI 发布语音客服新模型：MAI-Transcribe-2-Streaming 与 MAI-Voice-2.1 实时转录支持 60 种语言、首个字词 100 毫秒出，微软称在 Artificial Analysis 准确率第一，年内优惠价 0.54 美元/小时音频；TTS 的 MAI-Voice-2.1 可用同一音色说 23 种语言且带本地口音，Flash 版延迟 150 毫秒、每百万字符 15 美元（原 22 美元）；两个语音模型都能用几秒参考音频克隆音色。
